# 匹配评分规则 v1

来源：本地 offer-toolkit-skill（MIT，Copyright 2026 yanliudesign），已改为确定性本地计算。

## 单项分值

- `1`：当前素材包有直接、可讲清、可核验的证据。
- `0.5`：相邻经验、有说法但证据不足、角色参与度低于岗位要求。
- `0`：当前素材包没有证据。口头自信不能替代证据。

大于 0 的匹配必须引用当前素材包里的素材条目或 STAR 故事。

## 总分

```text
match = 0.6 * must-have average
      + 0.2 * nice-to-have average
      + 0.2 * hidden-signal average
```

保守上限：

- 1 条硬性要求未命中：最高 75%。
- 2 条及以上硬性要求未命中：最高 55%。
- 门槛型硬性要求未命中：最高 35%。

展示时使用 `score - 5%` 到 `score + 5%` 的区间，不把推断伪装成单点真值。

## 差距与风险

能力差距回答“用户缺什么”，招聘经理风险回答“对方会担心什么”。两者必须分开记录。差距分为：

- `recoverable_30_days`：可用已有材料重新组织、补作品或短期学习补齐。
- `hard_to_close`：需要行业年限、 leadership、特定规模或结构性条件。
- `low_priority`：非主线加分项，不干扰主要行动计划。
