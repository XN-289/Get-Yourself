# 模式: contract —— 三方协议/劳动合同解读

解读三方协议、劳动合同、offer 函的关键条款。**只做解释，不提供法律意见；涉及重大利益建议咨询学校就业指导中心或律师。**

## 输入

- 用户粘贴协议/合同文本（可脱敏）
- 或用户描述关键条款

## 解读维度

### 三方协议（就业协议书）

| 条款 | 说明 |
|------|------|
| 违约金 | 金额是否合理（通常 3k-10k；过高要警惕） |
| 违约金触发条件 | 什么情况要赔（毁约？考研上岸？考公上岸？） |
| 档案/户口去向 | 档案放哪、户口迁移 |
| 试用期 | 长度（1-6 个月，与合同期挂钩）、试用期薪资 |
| 合同期 | 3 年常见，注意违约金与合同期的关系 |
| 备注栏 | 有没有手写补充条款（薪资/岗位/城市，务必落实在备注） |

### 劳动合同

| 条款 | 说明 |
|------|------|
| 薪资结构 | base/绩效/年终的比例，绩效怎么算 |
| 五险一金 | 基数、比例 |
| 试用期 | 长度、工资（不得低于正式 80%） |
| 竞业限制 | 是否签、范围、补偿金（离职后每月补偿） |
| 加班 | 加班费/调休政策 |
| 解除条件 | 双方解除/单方解除的情形 |

### offer 函

| 条款 | 说明 |
|------|------|
| 有效期 | 多久内必须确认 |
| 薪资 | 是否写明具体数字（口头 offer 要落到书面） |
| 附带条件 | 毕业证/学位证/体检/背调 |

## 输出

```markdown
# 协议解读: {类型}

## 关键条款逐条
| 条款 | 原文摘要 | 解读 | 风险 |
|------|----------|------|------|
| 违约金 | 5000元 | 合理范围 | 低 |
| ... | | | |

## 风险点
- 高/中/低风险项各列出

## 建议
- 该确认的问题清单（问 HR/问学校）

## 免责
本解读仅供参考，不构成法律意见。重大利益请咨询专业人士。
```

## 规则

- **只描述，不评判**（同 career-ops offer-prep）：列出条款含义和风险，不下"该签/不该签"的命令
- 用户红线（`_profile.md`）相关的条款特别提示
- 明显异常（违约金 10 万+/空白条款/口头承诺）重点标注并建议咨询
