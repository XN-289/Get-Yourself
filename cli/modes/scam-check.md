# 模式: scam-check —— 防诈骗核查

对可疑岗位/招聘信息做防骗核查。**中国大学生是招聘诈骗的重灾区（培训贷、黑中介、"包就业"），此模式优先级高于一切评估。**

## 触发

- 用户粘贴可疑岗位/公司名/招聘信息
- 评估时 Block G 出现 🟡/🔴 信号
- 用户直觉"感觉不对"

## 核查清单

### 1. 公司真实性
- 工商信息：企查查/天眼查/国家企业信用信息公示系统
- 官网是否真实（域名注册时间、备案信息）
- 招聘信息是否与官网一致

### 2. 收费信号（🔴 一票否决）
- 入职前收费：培训费/服装费/押金/体检费异常高
- "贷款培训包就业"（培训贷）
- 无明确岗位只说"高薪"、"日结"、"月入过万"
- 需发展下线（传销特征）

### 3. 岗位真实性
- 职责是否具体，还是空话
- 薪资是否明显高于同岗位市场价（"刚毕业月薪 3 万"= 危险信号）
- 岗位要求是否自相矛盾

### 4. 招聘流程
- 正规流程：网申→笔试→面试→offer
- 异常：无面试直接录用、要求立即签约、面试地点可疑（非公司地址/居民楼/酒店）
- 远程面试是否要求下载不明软件

### 5. 中介/代招
- 通过中介投递且要求缴费
- "内推"收费（正规内推免费）
- "保 offer""包过"承诺

### 6. 话术异常
- HR 过度热情（"特别看好你"）
- 施压话术（"名额有限""今天不签就没了"）
- 要求提供身份证/银行卡信息过早

## 输出

```markdown
# 防骗核查: {公司/岗位}

## 结论: 🔴 高风险 / 🟡 需核实 / 🟢 正常

## 发现的风险信号
- [x] 信号1（证据）
- [x] 信号2（证据）

## 建议
- 立即停止/需核实/可以继续

## 核实方法（如需）
1. 查工商信息: ...
2. 打电话给公司官方电话确认 HR
3. 问学校就业指导中心
```

## 规则

- 🔴 有任一收费信号或传销特征 → **结论直接标 🔴，建议不投**，不做"但是"
- 证据不足时标 🟡，给核实方法，不臆断
- 只基于用户提供的信息 + WebSearch 结果，不编造
- 被骗风险 > 面子：宁可多疑，不要鼓励"试试看"
